# AGENTS.md

Project instructions for coding agents working in this repository.

## Commit messages

Do not add AI attribution of any kind to commit messages. Specifically, never
append:

- a `Generated with ...` line (with or without emoji), or
- a `Co-Authored-By` trailer naming an assistant, agent or tool,

or any similar attribution trailer. The commit message ends with its own last
line of text: subject, optional body, nothing else.

This applies to every commit in this repository, including commits made by
automated agents.
